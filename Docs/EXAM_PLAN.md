# Самый простой план действий как по мне

## ER-диаграмма

1. Просмотреть все файлы заказчика.
2. Выписать сущности.
3. Разнести повторяющиеся данные по таблицам.
4. Добавить PK/FK.
5. Проверить 3НФ(третья нормальная форма).
6. Экспортировать PDF.

## SQL Server

1. Создать БД.
2. Создать таблицы.
3. Создать FK, CHECK, UNIQUE.
4. Загрузить базовые данные.
5. Импортировать `Заказчики.json`.
6. Выполнить несколько SELECT для проверки.

## SQL расчет

1. JOIN заказов со строками заказа.
2. JOIN продукции со спецификацией материалов.
3. Умножить количество продукции на норму расхода и цену. (мне чапик посоветовал так делать)
4. Аналогично посчитать операции.
5. Сложить обе части.

## WinForms

1. Сначала сделать подключение к БД.
2. Затем таблицу просмотра.
3. Потом CRUD.
4. Потом только обязательные элементы из ТЗ.

## API и тесты

1. Запустить `HttpListener`.
2. Сделать health endpoint.
3. Сделать основной endpoint по заданию.
4. Реализовать обработку данных.
5. Проверить вручную.
6. Создать коллекцию тестов.

## документация

1. Открыть шаблон.
2. Для каждого метода указать URL, HTTP-метод, параметры.
3. Вставить пример запроса и ответа.
4. Проверить все файлы перед сдачей.
