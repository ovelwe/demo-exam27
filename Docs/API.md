# Документация к API "SIGMA-API"

## Общий адрес

`http://localhost:8080/`

## GET /api/health

быстрая проверка, что HTTP-сервис запущен.

Пример запроса:

```http
GET http://localhost:8080/api/health
```

Успешный ответ, HTTP 200:

```json
{"status":"ok"}
```

## GET /api/customers

получение списка покупателей.

В текущей демонстрационной реализации выполняется обработка данных: наружу выдаются только `id`, `name`, `type`; ИНН, адрес и телефон не возвращаются.

Пример запроса:

```http
GET http://localhost:8080/api/customers
```

Пример ответа:

```json
[
  {
    "id": 1,
    "name": "ИП Томилин Александр Сергеевич",
    "type": "Покупатель"
  }
]
```

Важно: на экзамене правило обработки заменить на то, которое будет указано в Приложении 2.

## GET /api/order-cost?orderId={id}

получение рассчитанной себестоимости заказа.

Параметр:

`orderId` - целочисленный идентификатор заказа.

Пример:

```http
GET http://localhost:8080/api/order-cost?orderId=1
```

Пример успешного ответа:

```json
{
  "orderId": 1,
  "customer": "ИП Томилин Александр Сергеевич",
  "materialCost": 9974.28,
  "operationCost": 5600.00,
  "totalCost": 15574.28
}
```

Ошибки:

- `400` - отсутствует или некорректен `orderId`
- `404` - заказ не найден
- `500` - внутренняя ошибка.
