## 2. Почему выбран SQL Server

В КИМ сказано создать БД на предоставленном сервере баз данных. Поэтому SQL Server а не SQLite как я хотел.

## 3. Как запустить БД

1. Открыть SQL Server Management Studio.
2. Подключиться к серверу.
3. Выполнить последовательно:

```text
Database/01_CreateDatabase.sql
Database/02_SeedDemoData.sql
Database/03_CostViewsAndQuery.sql
Database/04_Checks.sql
```

После этого должна появиться БД `DemoExam2027`.

## 4. Настройка строки подключения

Открыть `App.config`.

По умолчанию:

```text
Data Source=.\SQLEXPRESS;Initial Catalog=DemoExam2027;Integrated Security=True;TrustServerCertificate=True
```

Если на экзамене сервер называется иначе, меняется только `Data Source`.

Примеры:

```text
Data Source=.;...
Data Source=.\SQLEXPRESS;...
Data Source=SERVER01;...
```

## 5. Как запустить WinForms

1. Открыть `DemoExam.sln` в Visual Studio.
2. Убедиться, что установлен .NET Framework 8.
3. Проверить `App.config`.
4. Нажать `F5`.

Форму сделал кодом, без Designer, чтобы быстрее было. А так там тоже самое только вручную расставлять всё.

## 6. Импорт Заказчики.json

В приложении:

1. Открыть вкладку `Заказчики`.
2. Нажать `Импорт JSON`.
3. Выбрать `SourceData/Заказчики.json`.

Импорт выполняется как UPSERT по внешнему `id`: существующие записи обновляются, отсутствующие добавляются.

## 7. Как считается себестоимость

Для каждой строки заказа:

```text
стоимость материалов =
кол-во продукции * норма материала на изделие * текущая цена материала
```

```text
стоимость операций =
кол-во продукции * кол-во операций на изделие * текущая цена операции
```

```text
полная себестоимость = материалы + операции
```

Основная логика вынесена в SQL VIEW `dbo.v_OrderProductionCost`.

По текущему прайс-листу для заказа 1 из 2 столов получается:

```text
материалы: 9974.28
операции:  5600.00
итого:    15574.28
```

## 8. Как запустить API

В приложении открыть вкладку `API` и нажать `Запустить API`.

Адреса:

```text
http://localhost:8080/api/health
http://localhost:8080/api/customers
http://localhost:8080/api/order-cost?orderId=1
```

Если Windows выдает `Access is denied`, открыть командную строку от администратора и один раз выполнить:

```bat
netsh http add urlacl url=http://localhost:8080/ user=%USERNAME%
```

После работы правило можно удалить:

```bat
netsh http delete urlacl url=http://localhost:8080/
```

## 9. Тестирование API

Импортировать в Postman/другую прогу для тестов(для проверки работы апишника):

```text
Tests/DemoExam.postman_collection.json
```

Запустить коллекцию. Она проверяет:

- health endpoint
- список покупателей
- расчет заказа 1
- 404 для отсутствующего заказа
